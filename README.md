# WorldOrbDynVars

A [ResoniteModLoader](https://github.com/resonite-modding-group/ResoniteModLoader) mod for [Resonite](https://resonite.com/) that creates a "WorldOrbDynVars" dynamic variable space under your user for reading ContextMenu component data.

## Provided Variables

### WorldOrbDynVars/SelectedItem

Reference to the `ContextMenuItem` that is currently highlighted (`ReferenceCopy` of `ContextMenu._selectedItem`).

## Installation
1. Install [ResoniteModLoader](https://github.com/resonite-modding-group/ResoniteModLoader).
1. Place [WorldOrbDynVars.dll](https://github.com/Cyberboss/WorldOrbDynVars/releases/latest/download/WorldOrbDynVars.dll) into your `rml_mods` folder. This folder should be at `C:\Program Files (x86)\Steam\steamapps\common\Resonite\rml_mods` for a default Windows install. You can create it if it's missing, or if you launch the game once with ResoniteModLoader installed it will create this folder for you.
1. Start the game. If you want to verify that the mod is working you can check your Resonite logs.
